# الأمن السيبراني — صفحة هبوط عربية

تطبيق التصميم الأصلي من Figma باستخدام HTML وCSS وJavaScript، دون مكتبات أو خطوة بناء. يشمل التصميم نسخ الكمبيوتر والتابلت والموبايل، وتُحمّل الصور والأيقونات وخط Tajawal من الملفات المحلية.

## التشغيل

```bash
npm run dev
```

افتح `http://localhost:4173`. لا يلزم تشغيل `npm install`؛ خادم المعاينة يستخدم Node.js فقط. يمكن تغيير المنفذ باستخدام `npm run dev -- --port=4174`.

فحص JavaScript:

```bash
npm run check
```

تم التحقق في Chromium من مقاسات التصميم الثلاثة ومن عدم وجود تمرير أفقي بين 320 و1920 بكسل، مع اختبار القائمة والأسئلة الشائعة واختيار المسار والتحقق من النموذج. اختُبرت حالات نجاح وفشل الإرسال بمحاكاة محلية فقط. ملخص التحقق والصور موجودة محليًا في `.impeccable/review/`.

## الملفات

- `index.html`: محتوى الصفحة وحقول التسجيل والعناصر الدلالية.
- `styles.css`: ألوان ومسافات وخطوط التصميم والتنسيق المتجاوب.
- `script.js`: قائمة التنقل، اختيار المسار، التحقق من الحقول وإرسال النموذج عند ربطه.
- `assets/`: الأصول الأصلية وملفات الخط، مع مصدرها في `assets/ORIGINS.md`.
- `.impeccable/references/`: صور Figma المرجعية، وليست أصولًا تُستخدم في الصفحة.

## نموذج التسجيل

لا يوجد API حاليًا، حسب تأكيد المستخدم. النموذج يتحقق من الاسم والبريد والمسار، لكنه لا يرسل البيانات أو يخزنها، ويعرض حالة التسجيل غير المتاح دون ادعاء نجاح الإرسال.

عند توفر الخدمة، ضع عنوانها في خاصية `data-endpoint` لنموذج `registration-form` داخل `index.html`. يرسل النموذج طلب `POST` مع JSON:

```json
{
  "full_name": "اسم المتدرّب",
  "email": "name@example.com",
  "track": "fundamentals"
}
```

قيم المسار: `fundamentals`، `ethical-testing`، `threat-analysis`، `network-security`.
يتوقع الرد رمز HTTP ناجحًا؛ يمكن أن يحتوي JSON على `success` أو `status`، وتُعامل القيمة `false` كفشل. يلزم إعداد CORS في الخدمة إذا كانت على نطاق مختلف. لا يُعدّ خادم المعاينة خدمة استقبال للنموذج.

إجابات الأسئلة الشائعة مشتقة من نصوص التصميم الحالية ويمكن تعديلها داخل `index.html`. روابط «استكشف المسار» تختار المسار المناسب ثم تنقل إلى النموذج؛ رابط الخصوصية ينقل إلى ملاحظة استخدام البيانات الأصلية.

## النشر

الملفات اللازمة لأي استضافة ثابتة: `index.html`، `styles.css`، `script.js` ومجلد `assets/`. لا يلزم رفع أدوات المعاينة أو ملفات المراجعة.
